# 로컬 드래그와 서버 확인 표시 상태의 경계

Status: Accepted
Decided: 2026-10-01

캐릭터를 직접 잡아 옮기는 조작과 친구의 오버레이 표시 여부를 구분한다.
드래그는 사용자가 SIDEY의 입력 영역에서 시작한 명시적 조작이다. 이때의 포인터
좌표는 로컬 물리 계산에 일시적으로만 사용하며 전역 활동 수집이나 위치 기록으로
확장하지 않는다. 캐릭터의 배치와 궤적은 서버 및 다른 사용자에게 전송하지 않는다.
이 경계는 기존 전역 활동 신호 제한을 유지하면서 로컬 상호작용을 허용한다.

숨김·조용히 설정의 공유 상태는 서버가 확인한다. 클라이언트 Presence 필드만으로
표시하면 변조된 클라이언트가 변경 빈도와 알림 비용 제한을 우회할 수 있으므로,
서버는 계정별 변경 제한과 동일값 중복 제거를 적용한다. 저장된 설정만으로 접속을
추정하지 않으며 서버 발급 상태 식별자를 실제 살아 있는 Presence 연결과 결합한다.
여러 연결 중 정상 표시 중이거나 상태를 알 수 없는 연결이 있으면 전체 사용자를
숨김으로 단정하지 않는다. 메시지를 읽었는지 추정하는 기능으로 확대하지 않는다.

현재 동작은 [캐릭터 조작](../product/characters-and-projectiles.md)과
[메시징](../product/messaging.md)에 정의한다. 이번 구현은 macOS에 적용하며
다른 그룹 이용 여부 표시와 여러 그룹 동시 오버레이는 포함하지 않는다.
