# 그룹 뽑기 게임

같은 그룹에서 사다리, 제비뽑기, 룰렛을 만든다. 시작 항목은 그룹 친구를
추가하거나 그룹과 무관한 텍스트를 2~12개 직접 입력한다. 사다리는 시작 항목 수만큼
도착 항목도 입력한다. 직접 입력하는 시작·도착 항목은 각각 최대 15자로 제한하며
클라이언트와 서버가 같은 Unicode code point 기준으로 확인한다. 각자 게임을 열고
시작 버튼을 눌러 결과를 본다. 친구를 시작 항목으로 고른 게임에서는 가장자리 메신저와 같은 캐릭터를 보여 준다.
원래 메신저 캐릭터의 위치와 동작은 유지한다.

## 결과와 다시 보기

서버가 저장한 이벤트가 시작 항목, 도착 항목과 결과의 원본이다. 클라이언트는 결과를
새로 뽑지 않는다. 사다리는 서버의 항목별 배정에 맞는 연결선을 만들고, 제비는
서버 당첨 항목과 처음부터 연결된 종이를 꺼내며, 룰렛은 서버 당첨 칸 중앙에서
멈춘다. 이벤트 ID로 시각적 이동 계획을 결정하므로 다시 보기에서도 같은 장면이
나온다. 같은 문구를 여러 번 입력해도 각 입력 칸과 배정을 별도로 다룬다.

게임 기록은 24시간 동안 볼 수 있다. 만든 사람은 기록을 삭제할 수 있으며,
삭제하면 그룹 모두의 결과와 게임 아이콘이 사라진다. 삭제한 기록도 생성 횟수
제한에는 포함한다. 기록 목록에는 경과 시간 카운터를 표시하지 않고,
메신저의 게임 말풍선과 같은 픽셀 아이콘을 사용한다. 목록에는 게임 종류와 항목 수만
표시하며 당첨자·사다리 배정을 미리 노출하지 않는다. 참여 중인 그룹을 골라 기록을
조회하고 열거나 삭제할 수 있다. 기록의 그룹 선택은 현재 메신저 그룹을 바꾸지 않는다.

게임은 준비, 진행, 완료 상태로 구분한다. 진행 중에는 시작을 다시 누를 수 없고,
완료된 결과는 게임 안에 남는다. 시작·다시 보기·닫기 버튼은 실제 게임 그림 아래에
가까이 배치한다. 게임을 닫거나
바꾸거나 로그아웃하면 진행 중인 재생을 종료한다. 메신저에서 연 게임은 그룹을
전환할 때 닫고, 기록에서 연 게임은 메신저 그룹 전환과 별개로 유지한다. 해당 그룹의
멤버십을 잃으면 기록에서 연 게임도 닫는다. 모니터의
크기나 구성이 바뀌어도 진행률을 유지하며 장면을 다시 배치한다. 동작 줄이기
설정에서는 같은 게임 그래픽의 완료 상태로 짧게 전환한다.

## 화면 표현

게임은 투명한 무대 위에 도형으로 그린 기구와 작은 조작 버튼만 표시한다. 빈
영역은 뒤의 앱으로 클릭을 통과시킨다. 캐릭터의 기존 텍스처, 걷기 프레임과
이름표를 재사용하고 정수 배율과 nearest-neighbor 확대를 유지한다. 사진, 영상과
외부 다운로드 에셋은 쓰지 않는다. 정적인 도형은 캐시하고 움직이는 부분만 기본
30 FPS로 갱신한다.

게임 아이콘은 작은 픽셀 그림으로 표시하고 안내 말풍선은 아이콘 바로 위에 둔다.
채팅 말풍선이 나타나면 게임 말풍선이 그 위로 올라가고, 채팅이 사라지면 원래
자리로 돌아온다.

- 사다리는 연결선과 이동 경로가 같은 데이터를 쓴다. 시작 항목이 하나씩 실제 선을
  따라 움직이고 각자의 도착 항목 옆에 남는다. 파스텔 레일과 작은 출발·도착 표시로
  구성하고 생성 화면의 입력 제목은 ‘시작 항목’으로 표시한다.
- 제비뽑기는 시작 항목별 종이를 접고, 섞고, 서버 당첨 종이를 꺼내 펼친다.
  종이는 최대 4열의 카드로 배치하고, 긴 항목은 여러 줄로 표시한다. 캐릭터와
  이름은 별도 공간에 둔다. 종이의 둥근 모서리와 접힌 귀를 표현하고 뒷면에는 작은
  도장을 둔다. 접힌 뒷면에서 안쪽 내용이 비치지 않는다.
- 룰렛은 시작 항목 수만큼 같은 각도의 칸을 만들고 원판과 칸 내용을 함께 돌린다.
  고정된 지시침이 당첨 칸의 중앙을 가리킨다. 완료되면 원판이 흐려지고 당첨
  캐릭터·이름 또는 직접 입력한 항목이 중앙의 큰 카드로 튀어 올라 안착한다.
  동작 줄이기 설정에서는 튀는 동작 없이 결과를 표시한다.

게임 화면은 OS 보안 화면, DRM 앱, 권한이 높은 앱 또는 모든 독점 전체화면 게임
위에 나타난다고 보장하지 않는다.
