# 그룹 뽑기 게임

같은 그룹의 친구 2~12명이 사다리, 제비뽑기, 룰렛에 참여한다. 각자 게임을 열고
시작 버튼을 눌러 결과를 본다. 게임에 등장하는 동물은 가장자리 메신저에 보이는
친구와 같은 캐릭터이며, 원래 메신저 캐릭터의 위치와 동작은 유지한다.

## 결과와 다시 보기

서버가 저장한 이벤트가 참가자, 도착 항목과 결과의 원본이다. 클라이언트는 결과를
새로 뽑지 않는다. 사다리는 서버의 참가자별 배정에 맞는 연결선을 만들고, 제비는
서버 당첨자와 처음부터 연결된 종이를 꺼내며, 룰렛은 서버 당첨자의 칸 중앙에서
멈춘다. 이벤트 ID로 시각적 이동 계획을 결정하므로 다시 보기에서도 같은 장면이
나온다. 같은 도착 문구를 여러 번 입력해도 각 입력 칸과 배정을 별도로 다룬다.

게임은 준비, 진행, 완료 상태로 구분한다. 진행 중에는 시작을 다시 누를 수 없고,
완료된 결과는 게임 안에 남는다. 다시 보기와 닫기를 제공한다. 게임을 닫거나
바꾸고, 그룹을 전환하거나 로그아웃하면 진행 중인 재생을 종료한다. 모니터의
크기나 구성이 바뀌어도 진행률을 유지하며 장면을 다시 배치한다. 동작 줄이기
설정에서는 같은 게임 그래픽의 완료 상태로 짧게 전환한다.

## 화면 표현

게임은 투명한 무대 위에 도형으로 그린 기구와 작은 조작 버튼만 표시한다. 빈
영역은 뒤의 앱으로 클릭을 통과시킨다. 캐릭터의 기존 텍스처, 걷기 프레임과
이름표를 재사용하고 정수 배율과 nearest-neighbor 확대를 유지한다. 사진, 영상과
외부 다운로드 에셋은 쓰지 않는다. 정적인 도형은 캐시하고 움직이는 부분만 기본
30 FPS로 갱신한다.

- 사다리는 연결선과 이동 경로가 같은 데이터를 쓴다. 캐릭터가 한 명씩 실제 선을
  따라 움직이고 각자의 도착 항목 옆에 남는다.
- 제비뽑기는 참가자별 종이를 접고, 섞고, 서버 당첨자의 종이를 꺼내 펼친다.
  접힌 뒷면에서 안쪽 내용이 비치지 않는다.
- 룰렛은 참가자 수만큼 같은 각도의 칸을 만들고 원판과 칸 내용을 함께 돌린다.
  고정된 지시침이 당첨 칸의 중앙을 가리킨다.

게임 화면은 OS 보안 화면, DRM 앱, 권한이 높은 앱 또는 모든 독점 전체화면 게임
위에 나타난다고 보장하지 않는다.
