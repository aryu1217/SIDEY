피격 효과음과 기절 효과를 추가하고, 연결 상태와 설치 과정을 개선했어요.

## 새로운 기능

- 캐릭터 피격음 8종과 음소거·음량 조절을 추가했어요.
- 상점에서 투척물을 맞히거나 음량 조절을 마치면 효과음을 확인할 수 있어요.
- 10초 안에 10번 맞으면 별과 링이 표시되고, 6초 동안 이동·확대·던지기가 제한돼요.
- 캐릭터·말풍선·투척물을 장착하는 동안 진행 상태가 표시돼요.

## 개선 사항

- 캐릭터마다 닉네임의 높이를 일정하게 맞추고, 기절 효과가 가려지지 않도록 했어요.
- Windows에서 애니메이션을 끄면 상점 미리보기와 기절 효과도 움직임 없이 표시돼요.
- 앱을 시작하면 캐릭터가 먼저 회색 연결 대기 상태로 표시돼요.
- 네트워크 끊김 감지와 재연결을 개선했어요. 연결 상태를 눌러 다시 연결을 시도할 수 있어요.
- 설치 프로그램에 7개 언어 선택을 추가하고, 필수 구성 요소 설치를 개선했어요.
