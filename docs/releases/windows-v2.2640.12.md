ARM64 Windows 지원을 더하고, 업데이트와 친구 간 연결을 더 안정적으로 다듬었어요.

## 새로운 기능

- ARM64 Windows용 설치 파일과 자동 업데이트를 지원해요.
- 자동 다운로드·설치(기본 켜짐)와 새 버전 알림을 설정할 수 있으며, 데이터 통신 연결에서는 자동 업데이트를 건너뛰어요.

## 개선 사항

- 지원되는 업데이트에서는 바뀐 파일만 내려받아 다운로드 용량을 줄이고, 필요한 경우 전체 설치 파일로 전환해요.
- 최근 기록을 다시 열 때 저장해 둔 메시지를 먼저 보여 주어 기다림을 줄였어요.
- 업데이트 설정을 접고 펼칠 수 있고, 다운로드 진행률과 설치 준비 상태를 확인하기 쉬워졌어요.

## 버그 수정

- 그룹 멤버가 바뀌거나 일부 그룹의 연결에 문제가 생겨도 다른 그룹의 정상 연결을 유지하도록 고쳤어요.
- 일시적인 인증·연결 오류 뒤 메시지 수신을 복구하고, 늦게 도착한 조회 결과가 방금 보낸 메시지를 지우는 문제를 고쳤어요.
- 연결 복구 중 전송이 거절되면 작성한 메시지를 유지하도록 고쳤어요.
- 이미 최신 버전일 때 업데이트 확인만으로 설정 창이 나타나는 문제를 고쳤어요.
- 상점 안내 문구가 긴 경우 창 너비에 맞춰 줄바꿈하도록 고쳤어요.

## 설치 전 확인

설치 파일은 코드 서명되지 않아 Windows Smart App Control 등 보안 설정에 따라 실행이 차단될 수 있어요.
