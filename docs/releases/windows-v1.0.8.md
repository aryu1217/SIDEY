보유한 말풍선과 투척물을 Windows에서도 장착하고, 상점의 꾸미기를 움직이는 미리보기로 확인할 수 있어요.

## 새로운 기능

- 내 프로필에 말풍선과 투척물 선택 영역을 추가했어요. 계정에 보유한 꾸미기만 표시하며, 기본 말풍선과 캐릭터 기본 투척물로 언제든 돌아갈 수 있어요.
- 장착한 말풍선의 색상, 글자색, 픽셀 장식을 메시지와 입력 중 표시에 적용해요.
- 통통 하트, 미니 대포, 삑삑 오리를 오버레이에서 던질 수 있어요. 미니 대포에는 전용 발사 장치와 충돌 효과도 표시돼요.
- 상점에서 각 상품의 움직임을 30 FPS로 확인할 수 있는 상세 미리보기를 추가했어요.

## 개선 사항

- 상점의 상품을 캐릭터 4종, 말풍선 3종, 투척물 3종으로 늘렸어요.

## 이 버전의 안내

- 이 버전의 Windows 상점은 미리보기만 제공하며 구매할 수 없어요.
- GitHub 릴리즈에 첨부된 SIDEY-Windows-x64-v1.0.8-Setup.exe를 내려받아 실행하세요. 설치와 제거에는 관리자 승인이 필요하며, 새로 설치하거나 업데이트할 때 설치 화면에서 이용약관에 동의해야 해요.
- 기존 SIDEY 위에 업데이트하면 설정과 로그인 정보가 유지돼요. Windows v1.0.3 또는 v1.0.4에서는 앱 내 업데이트가 실패하므로 설치 파일을 직접 내려받아 설치하세요.
- Windows 설정 또는 Uninstall.exe로 제거할 때 설정·로그와 로그인 정보를 각각 삭제할지 선택할 수 있어요. 두 옵션은 기본적으로 꺼져 있으며, 선택한 데이터는 영구 삭제돼요.
- 이 버전은 Windows 11 25H2 이상 x64 PC를 지원해요.
- 이 버전에는 공인 코드 서명이 없어 SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있어요.
