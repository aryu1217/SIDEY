앱과 설치 프로그램의 언어 지원을 넓히고, 오버레이와 그룹 참여 동작을 개선했어요.

## 새로운 기능

- 앱과 설치 프로그램에서 한국어·영어·일본어·중국어 간체·중국어 번체·우크라이나어·러시아어를 지원해요.

## 개선 사항

- 설치할 때 선택한 언어로 앱이 처음 열려요. 설치 직후 앱을 실행하지 않아도 다음 실행에 적용돼요.
- 설정에서 언어를 바꾸면 창을 닫거나 연결을 다시 시작하지 않고 문구가 바로 바뀌어요.
- 한국어 문구를 macOS와 자연스럽게 맞추고, 다른 언어도 각 언어권에 어울리는 표현으로 다듬었어요.
- 오버레이가 부드럽게 나타나요. Windows에서 애니메이션 효과를 끄면 오버레이와 작업 표시줄 전환도 즉시 표시돼요.

## 버그 수정

- 그룹을 만들거나 초대 코드로 참여한 뒤 다음 화면으로 넘어가지 않던 문제를 고쳤어요.

## 이 버전의 안내

- 이 버전은 Windows 11 25H2 이상 x64 PC에서 사용할 수 있어요. GitHub 릴리즈에 첨부된 SIDEY-Windows-x64-v1.2.1-Setup.exe를 실행하세요. 기존 버전 위에 설치하면 설정과 로그인 정보가 유지돼요.
