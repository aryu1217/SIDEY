업데이트 설치 파일을 내려받을 때 파일 사용 중 오류로 중단되던 문제를 고쳤어요.

## 버그 수정

- 업데이트 파일을 내려받고 무결성을 확인한 뒤 설치 프로그램이 정상적으로 실행되도록 고쳤어요.

## 이 버전의 안내

- v1.0.4의 물체 던지기와 아홉 캐릭터 표시는 그대로 제공돼요.
- GitHub 릴리즈에 첨부된 SIDEY-Windows-x64-v1.0.5.msi를 직접 내려받아 실행하세요. 설치와 제거에는 관리자 승인이 필요해요.
- v1.0.3과 v1.0.4의 앱 내 업데이트에도 같은 오류가 있으므로 v1.0.5를 한 번 수동 설치해야 해요. 기존 버전 위에 설치하면 설정과 로그인 정보가 유지되며, 이후 업데이트부터는 앱 안에서 받을 수 있어요.
- Windows 설정, MSI 또는 Uninstall.exe로 제거할 때 설정·로그와 로그인 정보도 삭제할지 선택할 수 있어요. 기본적으로 선택되지 않으며, 선택하면 현재 사용자의 SIDEY 데이터가 영구 삭제돼요.
- 이 버전은 Windows 11 25H2 이상 x64 PC를 지원해요.
- 이 버전에는 공인 코드 서명이 없어 SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있어요.
- 과거 사용자별 설치 또는 Burn 방식의 Windows 테스트 버전이 설치되어 있다면 먼저 제거하세요.
