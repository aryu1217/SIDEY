언어 선택과 상점 미리보기를 개선하고, 메시지 입력창과 업데이트 동작을 다듬었어요.

## 새로운 기능

- 설정 페이지 하단에서 한국어·영어·일본어를 선택하면 재실행 없이 적용돼요.
- 상점 캐릭터 미리보기에서 상품 캐릭터를 두 번 클릭하면 커지고, 친구 캐릭터를 클릭하면 투척물을 던져요.

## 개선 사항

- 영어와 일본어 문구를 자연스럽게 다듬었어요. 날짜와 시간은 앱 언어와 관계없이 컴퓨터 설정을 따라요.
- 메시지 입력창이 제목 표시줄 없이 둥근 모서리로 표시돼요.
- 캐릭터의 방향 전환과 휴식, 투척 궤도와 대포 방향을 macOS와 맞췄어요.
- 미리보기에서 캐릭터를 확대하는 동안에도 닉네임이 표시돼요.
- 별빛 우파루파의 평상시 반짝임과 확대 효과, 투척물 충돌 효과를 개선했어요.
- 프로필의 말풍선·투척물에 마우스를 올리면 반응이 표시돼요. 활성 그룹은 같은 아이콘의 색상으로 구분해요.
- 마지막 확인 시간 자리에 업데이트 확인 상태를 표시하고, 다운로드 중에는 진행 비율을 보여줘요.
- 업데이트 설치 취소와 오류를 더 알기 쉽게 안내해요. 설치가 끝난 이전 업데이트 파일은 다음 앱 실행 때 정리해요.

## 버그 수정

- 메시지 입력창이 비정상적으로 종료되던 문제를 고쳤어요.
- 미리보기 투척물이 보이지 않거나 깜빡이던 문제와, 확대할 때 흐려지던 문제를 고쳤어요.
