말풍선, 처음 실행 설정, 연결 복구를 다듬고 최근 기록을 서버의 3일 보관 정책에 맞췄어요.

## 개선 사항

- 긴 메시지와 여러 말풍선의 배치와 표시를 개선했어요.
- 처음 실행 설정에서 기존 프로필과 그룹을 확인할 수 있고, 그룹 설정은 건너뛸 수 있어요.
- 네트워크나 모니터 구성이 바뀐 뒤에도 연결과 오버레이가 더 안정적으로 복구돼요.
- 최근 메시지와 기록의 조회·로컬 보관 기간을 생성 후 3일로 맞췄어요.

## 이 버전의 안내

- GitHub 릴리즈에 첨부된 SIDEY-Windows-x64-v1.0.7-Setup.exe를 실행하세요. 기존 설치 위에 업데이트하면 설정과 로그인 정보가 유지돼요.
- 이 버전은 Windows 11 25H2 이상 x64 PC를 지원해요.
- 추가 캐릭터 4종은 계속 미리보기로 제공하며, 이 버전의 Windows 앱에서는 구매할 수 없어요.
- 이 설치 파일에는 공인 코드 서명이 없어 SmartScreen 경고가 표시될 수 있어요.
- 보안 화면, 권한이 더 높은 앱, 모든 독점 전체 화면 게임 위에 표시되는 것은 보장하지 않아요.
