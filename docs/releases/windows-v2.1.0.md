새 캐릭터와 투척물을 더하고, 최근 기록과 설정 화면, 친구 간 연결을 개선했어요.

## 새로운 기능

- 시바견·오리·똥·떡볶이·쿼카 캐릭터 5종과 테니스공·휴지 뭉치·어묵꼬치·잎사귀 투척물 4종을 Windows 상점과 오버레이에 추가했어요.
- 최근 기록 창을 항상 위에 고정할 수 있어요.

## 개선 사항

- 앱에서 사용할 수 있는 언어를 23개로 늘렸어요.
- 최근 기록에서 이전 메시지를 읽던 위치를 유지해요.
- 단축키를 설정할 때 실제로 사용 중인 키 조합을 더 정확하게 안내해요.
- 구버전에서 업데이트할 때 기존 설정을 보존하며 설치 경로를 안전하게 옮겨요.

## 버그 수정

- 캐릭터를 두 번 클릭할 때 메시지 입력창이 잠깐 나타나는 문제를 고쳤어요.
- 화면 가장자리에서 캐릭터 닉네임이 틀어져 보이는 문제를 고쳤어요.
- 다른 버전 사용자와 주고받는 메시지·투척 반응이 누락되는 문제를 개선했어요.
- 여러 방에서 연결이 끊겼다가 복구될 때 시간 초과가 발생하는 문제를 고쳤어요.
