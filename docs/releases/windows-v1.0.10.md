프로필과 상점의 배치를 정리하고, 미리보기와 업데이트의 안정성을 개선했어요.

## 개선 사항

- 프로필의 캐릭터·말풍선·투척물 선택 영역을 각각 5열·4열·4열로 고르게 배치하고, 선택 표시와 내용을 가운데에 맞췄어요.
- 상점에서 캐릭터·말풍선·투척물을 탭으로 전환하고, 필요할 때만 필터를 펼칠 수 있어요. 페이지와 탭을 전환할 때 짧은 애니메이션도 적용했어요.
- 꾸미기 미리보기의 크기와 말풍선 모양, 걷기·투척 속도와 궤적을 실제 오버레이와 더 가깝게 맞췄어요.
- 업데이트 확인과 다운로드 진행 상태를 표시해요. 설정창을 닫아 트레이로 보내도 다운로드는 계속돼요.
- 업데이트 알림을 다른 시스템 알림과 같은 정보 알림 형태로 표시해요.

## 버그 수정

- 물건을 던지거나 맞을 때 캐릭터가 180도 뒤집히던 문제와 미리보기에서 캐릭터가 깜빡이던 문제를 고쳤어요.
- 창을 닫는 동안 남은 화면 작업과 꾸미기 이미지 로딩을 정리해, 앱이 비정상적으로 종료될 가능성을 줄였어요.

## 이 버전의 안내

- 이 버전의 Windows 상점은 미리보기만 제공하며, 구매 기능은 사용할 수 없어요.
