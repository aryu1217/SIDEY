설정 화면과 연결 복구를 개선하고, 계정에 지급된 캐릭터 선택과 그룹 나가기를 추가했어요.

## 새로운 기능

- 프로필에서 무료 캐릭터와 계정에 지급된 캐릭터를 선택할 수 있어요.
- 상점에서 추가 캐릭터 4종을 미리 볼 수 있어요.
- 그룹 나가기 기능을 추가했어요.

## 개선 사항

- 설정 창이 좁아지면 탐색 메뉴가 아이콘으로 접히도록 바꿨어요.
- 잠깐 끊긴 연결은 조용히 복구하고, 오래 끊긴 경우에만 알림을 표시해요.
- 작업 중 중복 요청을 막고, 메시지 입력창의 포커스와 전송 아이콘을 개선했어요.
- 설치 프로그램을 Setup EXE로 바꿨어요. 설치 위치 선택, 같은 버전의 복구·제거, 이전 정식 MSI에서의 업데이트를 지원해요.

## 버그 수정

- 좁은 설정 창에서 연결 상태가 겹치거나 잘리는 문제를 고쳤어요.

## 이 버전의 안내

- 이 버전의 Windows 앱에서는 구매할 수 없어요.
- GitHub 릴리즈에 첨부된 SIDEY-Windows-x64-v1.0.6-Setup.exe를 내려받아 실행하세요. 설치와 제거에는 관리자 승인이 필요하며, 새로 설치하거나 업데이트할 때 설치 화면에서 이용약관에 동의해야 해요.
- 이전 정식 MSI는 설치 프로그램이 제거한 뒤 같은 위치에 새 버전을 설치하며, 설정과 로그인 정보는 유지돼요. v1.0.3 또는 v1.0.4에서는 앱 내 업데이트가 실패하므로 설치 파일을 직접 내려받아 설치하세요.
- 과거 사용자별 설치 또는 Burn 방식의 테스트 버전은 먼저 Windows 설정에서 제거하세요.
- Windows 설정 또는 Uninstall.exe로 제거할 때 설정·로그와 로그인 정보를 각각 삭제할지 선택할 수 있어요. 두 옵션은 기본적으로 꺼져 있으며, 선택한 데이터는 영구 삭제돼요.
- 이 버전은 Windows 11 25H2 이상 x64 PC를 지원해요.
- 이 버전에는 공인 코드 서명이 없어 SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있어요.
