Google 계정 연결과 계정 관리 흐름을 정리하고, 채팅·단축키·오버레이 사용성을 개선했어요.

## 새로운 기능

- 설정에서 로그아웃하거나 회원 탈퇴할 수 있어요.
- 최근 기록에서 바로 메시지를 보내고, 입력창을 끌어 옮긴 위치를 다음 실행에도 유지할 수 있어요.
- 오버레이·조용히 모드·메시지 입력창·최근 기록 단축키를 원하는 키 조합으로 기록하고 중복 조합을 교환할 수 있어요.
- 앱에서 상품 가격과 보유 상태를 확인하고 웹 구매 화면으로 이동할 수 있어요.

## 개선 사항

- Google 로그인을 필수 초기 설정에 통합하고, 저장된 로그인 상태를 확인하는 동안 로그인 버튼을 잠가 중복 인증을 막아요.
- 계정 연결을 해제하면 실시간 연결과 로컬 상태를 정리한 뒤 로그인 화면으로 돌아가요.
- 조용히 모드에서는 입력 중 표시를 숨기고, 오버레이를 닫을 때 애니메이션이 끝까지 자연스럽게 재생돼요.
- 로그인 인증 후 앱으로 돌아오는 흐름과 실시간 입력 중 반응을 개선했어요.
- 설치 파일에 필요한 Windows App SDK와 .NET 런타임을 포함하고, 업데이트·복구·제거 실패 시 복원과 안내를 강화했어요.
- 실시간 연결 오류를 원인별로 안내하고, 재연결 과정에서 생기는 불필요한 오류 메시지는 숨겨요.
- 내 나무의 걷기 상태가 같은 그룹의 사용자에게 공유돼요.
- 밝은 테마와 어두운 테마에서 앱 안의 상태 알림을 더 쉽게 읽을 수 있어요.

## 버그 수정

- 캐릭터를 한 번 클릭할 때만 메시지 입력창이 열리도록 고쳤어요.
- 이미 실행 중인 앱을 다시 열면 기존 창으로 안전하게 전환돼요.
