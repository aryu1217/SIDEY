Windows용 SIDEY를 정식 출시했어요.

## 새로운 기능

- 처음 실행 설정과 프로필·그룹 관리 화면을 추가했어요.
- Windows에서도 다섯 캐릭터의 상태, 입력 중 표시, 메시지와 최근 기록을 확인할 수 있어요.
- 트레이 메뉴, 다중 모니터 배치, 조용히 모드와 업데이트 확인 기능을 추가했어요.
- 설치 폴더와 시작 메뉴에서 Uninstall.exe를 실행할 수 있어요.

## 개선 사항

- 한국어·영어 표시와 앱 실행 안정성을 개선했어요.

## 이 버전의 안내

- GitHub 릴리즈에 첨부된 SIDEY-Windows-x64-v1.0.3.msi를 내려받아 실행하세요. 설치와 제거에는 관리자 승인이 필요해요.
- Windows 설정, MSI 또는 Uninstall.exe로 제거할 때 설정·로그와 로그인 정보도 삭제할지 선택할 수 있어요. 기본적으로 선택되지 않으며, 선택하면 현재 사용자의 SIDEY 데이터가 영구 삭제돼요.
- 이 버전은 Windows 11 25H2 이상 x64 PC를 지원해요.
- 기존 Windows 테스트 버전이 설치되어 있다면 먼저 제거하세요. 테스트 설치의 데이터 보존 여부는 설치 방식에 따라 달라요.
