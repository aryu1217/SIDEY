새 캐릭터와 투척물을 지원하고 테마 선택과 상점 사용성을 개선했어요.

## 새로운 기능

- 아기 수달·아기 돼지·나무와 눈송이·야구공·왁뿌볼·두쫀쿠, 캐릭터별 애착 물건 7종을 미리 보고 보유 상품을 사용할 수 있어요.
- 내 나무를 한 번 우클릭하면 걷기를 멈추거나 다시 시작해요.
- ‘더블 우클릭 후 던지기’를 켜면 내 캐릭터를 두 번 우클릭한 뒤 친구를 클릭해 물건을 던져요.
- 밝게·어둡게·Windows 기본값 테마를 선택하고 입력창과 최근 기록에도 적용할 수 있어요.
- 정보 화면에서 진단 데이터를 내보낼 수 있어요.

## 개선 사항

- 캐릭터와 별도로 판매되는 애착 물건의 가격·보유 상태를 함께 확인하며, 투척물을 장착하지 않으면 기본 말랑공을 사용해요.
- 상점의 긴 상품명·미리보기·스크롤과 로딩 표시를 개선했어요.
- 트레이에서 업데이트를 확인하면 설정창을 열지 않고 Windows 알림으로 결과를 받아요.
- 설치 오류 안내와 내부 안정성을 개선했어요.

## 버그 수정

- 앱 안에서 업데이트할 때 설치가 중단되는 문제를 고쳤어요.

## 이 버전의 안내

- 이 버전은 Windows 11 25H2 이상 x64 PC용이에요. 해당 버전의 Setup EXE로 기존 버전 위에 설치하면 설정과 로그인 정보가 유지돼요.
- 1.3.0 설치 중 오류가 발생했다면 해당 릴리즈의 설치 파일을 다시 내려받아 실행하세요.
- v1.0.3·v1.0.4에서는 앱 안에서 업데이트 파일을 내려받을 수 없으므로 최신 설치 파일을 직접 받아 설치해야 해요.
- 이 버전은 앱 내 구매를 지원하지 않으며, 연결한 계정의 보유 상품을 확인한 뒤 사용할 수 있어요.
- 이 버전은 공인 코드 서명 전 정식판으로, SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있어요.
