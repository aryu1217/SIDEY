Windows에서도 친구 캐릭터와 물체를 주고받을 수 있어요.

## 새로운 기능

- 친구 캐릭터를 클릭하면 바로 물체를 던져요.
- 설정에서 ‘우클릭 후 던지기’를 켜면 내 캐릭터를 우클릭한 뒤 10초 동안만 던질 수 있어요.
- 온라인, 자리 비움, 오프라인, 연결 중인 친구 모두를 대상으로 선택할 수 있어요.
- macOS에서 선택한 기니피그, 원숭이, 친칠라, 별빛 우파루파가 Windows에서도 실제 모습과 각 캐릭터의 전용 물체로 표시돼요.

## 이 버전의 안내

- 이 버전의 Windows 캐릭터 선택 목록은 기존 무료 5종을 유지하며, 구매는 지원하지 않아요.
- GitHub 릴리즈에 첨부된 SIDEY-Windows-x64-v1.0.4.msi를 내려받아 실행하세요. 설치와 제거에는 관리자 승인이 필요해요. 기존 v1.0.3 위에 설치하면 설정과 로그인 정보가 유지돼요.
- Windows 설정, MSI 또는 Uninstall.exe로 제거할 때 설정·로그와 로그인 정보도 삭제할지 선택할 수 있어요. 기본적으로 선택되지 않으며, 선택하면 현재 사용자의 SIDEY 데이터가 영구 삭제돼요.
- 이 버전은 Windows 11 25H2 이상 x64 PC를 지원해요.
- 이 버전에는 공인 코드 서명이 없어 SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있어요.
- 과거 사용자별 설치 또는 Burn 방식의 Windows 테스트 버전이 설치되어 있다면 먼저 제거하세요.
