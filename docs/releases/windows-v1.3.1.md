Windows 실행 호환 범위를 넓히고 창 크기 변경, 프로필 선택과 투척물 표시의 안정성을 개선했어요.

## 개선 사항

- Windows 10 1809 이상 x64로 지원 범위를 넓히고, 지원하지 않는 배경 효과와 아이콘은 기본 표시로 대체해요.
- 좁은 창에서도 프로필 입력창과 선택 항목이 잘 보이도록 배치를 개선했어요.
- 밝은 테마와 어두운 테마에서 창 버튼을 구분하기 쉽게 하고, 프로필·그룹·상점의 로딩 표시를 개선했어요.
- 저장한 닉네임과 캐릭터가 내 그룹에도 함께 반영돼요.
- 설치 파일과 내부 안정성을 개선했어요.

## 버그 수정

- 창 크기를 바꿀 때 앱이 종료되는 문제를 고쳤어요.
- 프로필 갱신 중 캐릭터 선택이 바뀌는 문제를 고쳤어요.
- 투척물이 다른 물건으로 표시되는 문제와 상점에서 연속으로 물건을 던질 때 동작이 끊기는 문제를 고쳤어요.

## 이 버전의 안내

- 이 버전은 Windows 10 1809 이상 x64 PC용이에요. 해당 버전의 Setup EXE로 기존 버전 위에 설치하면 설정과 로그인 정보가 유지돼요.
- 이 버전은 앱 내 구매를 지원하지 않으며, 연결한 계정의 보유 상품을 확인한 뒤 사용할 수 있어요.
- 이 버전은 공인 코드 서명 전 정식판으로, SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있어요.
